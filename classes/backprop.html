Redes Neurais Profundas

Introdução aos fundamentos matemáticos de redes neurais, propagação direta, gradientes e backpropagation.

O que é uma Rede Neural?

  • Modelo inspirado no cérebro humano.
  • Composta por neurônios artificiais.
  • Aprende padrões a partir de dados.
  • Muito utilizada em NLP, visão computacional e IA generativa.

Estrutura Básica

  • Camada de entrada
  • Camadas ocultas
  • Camada de saída
y = f(Wx + b)

Neurônio Artificial

Um neurônio recebe entradas, aplica pesos, soma tudo e utiliza uma função de ativação.

z = w_1x_1 + w_2x_2 + ... + b

Funções de Ativação

  • Sigmoid
  • Tanh
  • ReLU
  • GELU

Sigmoid

\sigma(x)=\frac{1}{1+e^{-x}}

Transforma valores em probabilidades entre 0 e 1.

Problema da Sigmoid

  • Gradientes muito pequenos.
  • Treinamento lento.
  • Vanishing Gradient.

ReLU

ReLU(x)=max(0,x)

Hoje é uma das funções mais utilizadas em deep learning.

Forward Propagation

Os dados passam camada por camada até gerar uma previsão.

h = f(Wx+b)

Função de Perda

Mede o erro da rede neural.

L = (y - \hat{y})^2

Objetivo do Treinamento

  • Minimizar a perda.
  • Ajustar pesos automaticamente.
  • Encontrar padrões úteis.

Gradientes

Gradientes indicam como os pesos devem mudar para reduzir o erro.

\frac{\partial L}{\partial w}

Derivadas Parciais

Permitem calcular o impacto individual de cada parâmetro.

Regra da Cadeia

Base matemática do backpropagation.

\frac{dz}{dx}=\frac{dz}{dy}\cdot\frac{dy}{dx}

Redes Neurais em NLP

Modelos neurais substituíram pipelines manuais em NLP moderno.

  • Representações distribuídas
  • Aprendizado fim a fim
  • Generalização sem engenharia manual excessiva

Classificação com Rede Neural

Estrutura feed-forward com projeções lineares e softmax.

Camadas Ocultas

Camadas intermediárias aprendem representações não lineares.

Intuição Geométrica

Redes neurais transformam espaços vetoriais em representações mais separáveis.

Composição de Funções

Deep learning pode ser visto como composição sucessiva de funções.

Diferenciação Automática

Frameworks modernos constroem grafos computacionais dinamicamente.

Grafos Computacionais

Cada operação matemática vira um nó no grafo.

Forward Pass

  • Entrada percorre o grafo.
  • Ativações são computadas.
  • Obtém-se a previsão final.

Backward Pass

  • Gradientes percorrem o grafo ao contrário.
  • Aplicação da regra da cadeia.
  • Cálculo eficiente de derivadas.

Backpropagation

  • Calcula gradientes de trás para frente.
  • Atualiza pesos.
  • Treina redes profundas.

Etapas do Backpropagation

  1. Forward pass
  2. Cálculo da perda
  3. Cálculo dos gradientes
  4. Atualização dos pesos

Gradient Descent

w = w - \eta \nabla L

Atualiza os pesos na direção oposta ao gradiente.

Learning Rate

  • Muito alto: treinamento instável.
  • Muito baixo: treinamento lento.

Batch Training

  • Batch Gradient Descent
  • Stochastic Gradient Descent
  • Mini-batch Gradient Descent

Overfitting

O modelo memoriza os dados de treino e falha em generalizar.

Técnicas de Regularização

  • Dropout
  • L2 Regularization
  • Early Stopping

Inicialização de Pesos

Pesos ruins podem impedir o aprendizado adequado.

Vanishing Gradient

Gradientes desaparecem em redes profundas.

Exploding Gradient

Gradientes crescem excessivamente e tornam o treinamento instável.

Normalização

  • Batch Normalization
  • Layer Normalization

Representações Vetoriais

Palavras podem ser representadas como vetores densos.

Embeddings

Capturam relações semânticas entre palavras.

Redes Neurais em NLP

  • Classificação de texto
  • Tradução automática
  • Modelos de linguagem
  • Chatbots

Softmax

softmax(x_i)=\frac{e^{x_i}}{\sum_j e^{x_j}}

Cross Entropy Loss

L=-\sum y log(\hat{y})

Treinamento Iterativo

  • Epochs
  • Forward pass
  • Backward pass
  • Atualização de pesos

Otimização Moderna

  • Adam
  • RMSProp
  • Momentum

Adam Optimizer

Combina momentum e adaptação dinâmica da taxa de aprendizado.

Deep Learning

Redes profundas conseguem aprender representações complexas automaticamente.

Transformers

Arquitetura dominante em NLP moderno.

Atenção

Attention(Q,K,V)=softmax\left(\frac{QK^T}{\sqrt{d_k}}\right)V

LLMs

  • GPT
  • Llama
  • Gemini
  • Claude

Treinamento em GPUs

Treinar redes profundas exige grande capacidade computacional.

PyTorch

Framework popular para pesquisa e desenvolvimento de modelos neurais.

TensorFlow

Outra plataforma amplamente usada em produção.

Autograd

Bibliotecas modernas calculam gradientes automaticamente.

Treinamento Distribuído

Grandes modelos são treinados em múltiplas GPUs e clusters.

Fine-tuning

Adaptação de modelos pré-treinados para tarefas específicas.

Transfer Learning

Reutilização de conhecimento aprendido anteriormente.

Desafios

  • Custo computacional
  • Viés nos dados
  • Explicabilidade
  • Consumo energético

Conclusão

Backpropagation e gradientes são os pilares do aprendizado profundo moderno.

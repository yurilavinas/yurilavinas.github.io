Backpropagation - Otimização dos pesos

  • Calcula gradientes.
  • Atualiza pesos.
  • Usa descida do gradiente.

Por Que Otimização?

Treinar uma rede neural significa encontrar os pesos que minimizam uma função de custo.
  • Milhões de parâmetros
  • Espaços de alta dimensionalidade
  • Superfícies não convexas

O Conceito de Gradiente

O gradiente aponta para a direção de maior crescimento da função.

Gradient Descent


        # Vanilla Gradient Descent

        while True:
            weights_grad = evaluate_gradient(loss_fun, data, weights)
            weights += -step_size * weights_grad
  • η: taxa de aprendizado
  • Movimento na direção oposta ao gradiente
  • Busca pelo mínimo da função

Intuição Visual

  • Bola descendo uma montanha
  • O gradiente indica a inclinação local
  • Atualizações sucessivas convergem ao mínimo

Expressões Simples

f(x,y,z) = (x + y)z
  • q = x + y
  • f = q · z

:contentReference[oaicite:3]{index=3}

Forward Pass

x = -2
y = 5
z = -4

q = x + y = 3
f = qz = -12

Backward Pass

∂f/∂z = q = 3
∂f/∂q = z = -4
Agora propagamos para trás usando a regra da cadeia.

Regra da Cadeia

:contentReference[oaicite:4]{index=4}
  • dq/dx = 1
  • df/dx = -4
  • df/dy = -4

Backpropagation

Propagação reversa eficiente dos gradientes através do grafo computacional.
  • Executa da saída para a entrada
  • Reutiliza cálculos
  • Complexidade linear

Fluxo dos Gradientes

  • Sinais viajam para trás
  • Cada operação calcula gradientes locais
  • Multiplicação pela derivada local

Portas Computacionais

  • Soma: distribui gradiente
  • Máximo: roteia gradiente
  • Produto: troca entradas

:contentReference[oaicite:5]{index=5}

Porta Soma

:contentReference[oaicite:6]{index=6}
  • ∂f/∂x = 1
  • ∂f/∂y = 1
  • Gradiente é copiado para ambas entradas

Porta Multiplicação

:contentReference[oaicite:7]{index=7}
  • ∂f/∂x = y
  • ∂f/∂y = x

Porta Máximo

:contentReference[oaicite:8]{index=8}
  • Gradiente vai apenas para o maior valor
  • O outro recebe zero
